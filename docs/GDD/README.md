# PET SHOP ADMIN - Documentacao Oficial

Este arquivo e o indice mestre da documentacao oficial de PET SHOP ADMIN e serve como ponto de entrada para design, arquitetura, producao e operacao do projeto.

## Visao Geral
PET SHOP ADMIN e um jogo mobile F2P de Idle Tycoon/Management onde o jogador transforma um pequeno pet shop em uma rede completa de cuidados para animais.

## Resumo Executivo
- Produto: Casual Mobile com sessoes curtas e progressao longa.
- Plataforma: Android e iOS.
- Engine: Unity 6 (URP, New Input System, Addressables, Scriptable Objects).
- Publico: 13-45 anos, jogadores de tycoon idle.
- Referencias: Pizza Ready, Burger Please, My Perfect Hotel, Idle Pet Shop.

## Mapa de Documentacao
- Produto e visao: conceito, pilares, publico, posicionamento e escopo.
- Core design: gameplay, game loop, animais, estacoes, funcionarios, IA, progressao e upgrades.
- Economia e operacao: idle system, monetizacao, missoes, conquistas e save.
- Tecnica: arquitetura Unity, scriptable objects, UI/UX, audio e otimizacao.
- Producao: ADRs, roadmap, backlog inicial, diagramas operacionais e curadoria de assets.
